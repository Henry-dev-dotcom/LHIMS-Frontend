# LHIMS user guides

Short, task-based guides for each kind of user. Menu names are shown in **bold**; you only see
the menus for your job and for the departments your facility has switched on.

| Guide | For |
|---|---|
| [Getting started](getting-started.md) | Everyone: signing in, the facility code, your password |
| [Administrator](administrator.md) | Facility administrators: setup, staff, roles, prices, billing, data |
| [Reception](reception.md) | Front desk: registering patients, check-in, appointments |
| [Outpatients and emergency](outpatients-emergency.md) | Nurses and doctors: triage, consultation, prescriptions |
| [Wards and theatre](wards-theatre.md) | Ward nurses, doctors, theatre teams |
| [Maternity, child health and clinics](maternity-child-clinics.md) | Midwives, child welfare, dental, eye, physiotherapy, dietetics |
| [Laboratory and imaging](laboratory-imaging.md) | Lab scientists, radiographers, radiologists |
| [Pharmacy](pharmacy.md) | Pharmacists |
| [Billing, finance and claims](billing-finance-claims.md) | Cashiers, accounts, NHIS claims officers |
| [Stores, HR and medical records](stores-hr-records.md) | Storekeepers, HR, records officers |
| [Blood bank and mortuary](bloodbank-mortuary.md) | Blood bank staff, mortuary attendants |
| [Platform operator](platform-operator.md) | The LHIMS operator: facilities, plans, support |

API reference for developers: `/api/docs` on a server with docs switched on, or
`docs/openapi.json` in the backend repository.
